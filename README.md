# IOS-Development-journey-day-01

Small Swift codebase for a **90-day, 90-minutes/day, single tech stack** journey focused on **iOS Development (Swift + SwiftUI)**.

## What this includes
- A simple model for daily sessions (`PracticeSession`)
- A generator for the full 90-day plan (`IOSNinetyDayPlan.generate()`)
- Focused tests that verify:
  - 90 total sessions
  - 90 minutes per session
  - iOS single-stack focus for every day
  - phased topic progression

## Run tests
```bash
swift test
```
